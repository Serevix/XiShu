# 实现与验证说明

本文保留早期实现和评测记录，不作为最新统计。此前合成数据基准见 [完整验证](acceptance-2026-10-10.md)，原始真实数据评测结果保存在项目的 evaluations/results 中。

## 系统如何工作

用户注册后拥有独立数据集。上传四类文件并确认字段与口径，Worker 验证全部数据后在同一 PostgreSQL 事务中插入四张表。数据集就绪后才能创建分析任务。

分析任务先保存在 PostgreSQL，再投递到 Redis/Celery。Worker 获取任务级 advisory lock，加载或恢复 LangGraph checkpoint。真实模型根据消息与中间结果选择动作；演示模式通过显式规则选择动作。程序检查预算、权限和取消状态。

SQL 在独立非超级用户角色下执行。数据库行级策略读取服务端设定的事务内数据集上下文。即使模型遗漏数据集条件，也只能看到当前数据集。SQL 解析器限制表、函数与操作；事务只读并设置超时。超出结果限额时明确失败，不静默截断。

Python 只读挂载一个授权 CSV，输出目录单独挂载。容器无网络、无额外 Linux capability、不允许获取新权限，限制 CPU、内存、进程和执行时长。Docker 调度只在可信服务端进行，容器不挂载 Docker socket。

图表通过固定绘图实现生成；报告表格从实际结果文件生成。自由说明不得自行增加数字。产物保存来源引用，下载必须通过用户归属和任务登记检查。

正常统计窗口函数支持 LAG/LEAD；分析除法标准化为 NUMERIC，避免计数相除被整数截断。澄清后的指标与日期也参与核验。只有说明数字连续核验失败时，可丢弃模型说明、再次检查全部产物并交付明确标注的工具事实报告；缺列、缺必要工具、状态约束错误和图表不完整仍失败。

人工澄清使用 interrupt，任务等待输入并释放 Worker。补充后使用同一线程恢复。Beat 扫描待执行和失联任务并补投；执行锁防止并发重复运行。

## 数据库与状态

应用表共十一张：`users`、`datasets`、`analysis_tasks`、`customers`、`products`、`orders`、`order_items`、`analysis_conversations`、`conversation_messages`、`user_memories`、`user_question_patterns`。checkpoint 表由组件管理；记忆向量保存在独立 Milvus 数据库。

初始建表 SQL 在 `migrations/001_initial.sql`，初始化脚本同时配置只读角色和 RLS。写入连接沿用现有开发数据库用户；正式部署应按运维要求进一步收紧写入账号。

事件当前保存在任务 JSONB 中，通过行锁追加，SSE 按序号补读。这对初始 JSONL 方案做了调整，统一由数据库持久化便于原子更新。任务步骤受限；高并发或大量事件时应迁移到专门事件表。

终态与对应结束事件同事务保存；用户取消获胜时，迟到 Worker 不能再发布成功结束事件。

## 已验证的内容

- 单元测试：危险 SQL/Python、重复主键、金额精度、CSV 公式保护、模拟数据标准结果。
- 模型协议：模拟 HTTP 验证工具调用参数和 usage，不消耗远程费用。
- 集成：真实 PostgreSQL 导入、SQL/绘图/Python/报告、澄清恢复、取消、XLSX、导入失败回滚。
- 隔离：其他用户访问失败；显式查询其他数据集返回零行；只读连接无上下文不可见行且不能 UPDATE。
- 注释：AST 检查所有 Python 函数有 docstring。

## 当前边界

- 内置数据是模拟数据；已下载官方 Olist 并完成两个月真实时间切片评测，尚未对完整数据集实测。
- 本地已配置硅基流动 DeepSeek-V4-Flash；实际调用检查见验证记录。规则演示成功率不能当作真实 Agent 成功率，小规模模型检查不代表完整业务效果。
- 支持规范四表及显式映射，不支持任意 Excel 布局或外部数据库连接。
- 数值可追溯不等于任意 SQL 都符合业务语义，需要标准结果和人工评测补充。
- 分析执行器强制当前有效订单状态，跨状态比较需要单独设计口径。单图超过 200 行或维度重复时明确要求聚合/分组，不静默截取；报告输出完整受限表格。
- 取消在步骤边界生效；已经开始的 SQL、模型请求和容器计算可能等待各自有限时限。
- 当前展示步骤事件与最终结果，不提供模型文字逐 Token 输出。
- 只提供全局模型配置，没有每用户模型配置、浏览器搜索和多 Agent。长期记忆与会话摘要现已增加，详见 [新增功能说明](../../../docs/03-上下文管理与长期记忆.md)。
- 就绪快照不可覆盖；有任务引用的数据集不能删除。数据库删除暂不删除上传文件。
- 初始化脚本尚不包含后续模型变更的自动版本迁移。
- 当前已有真实 Olist 时间切片的端到端模型评测，仍未完成大规模模型比较、完整 Olist、账单成本基线和生产并发验证。报告依据校验尚不能保证业务计算语义正确。
