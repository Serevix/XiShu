# 析数 Agent 交互式阅读教程

优先打开本目录的 **index.html**。页面已经内嵌全部讲解数据，脚本、图表渲染和语法高亮依赖也保存在本地 vendor 目录；请保留整个文件夹，不要单独移动 index.html。

如浏览器限制本地文件，可在当前项目环境下运行：

```powershell
python -m http.server 8420 --bind 127.0.0.1 --directory .\project-learning-output
```

随后打开 http://127.0.0.1:8420 。也可从项目根目录运行 `.\project-learning-output\打开教程.ps1`。这只是静态教程服务，不启动业务系统、不访问数据库或模型。

## 建议阅读方式

1. 第一轮先读业务、架构、数据模型与完整案例，画出上传和分析交付两条调用链。
2. 第二轮读模块设计推导，再展开函数代码，对照 L1、L2 等逐行解释。代码卡片的行号从本片段第一行开始；卡片标题保留原文件范围。
3. 第三轮先回答情境推演与面试题，再展开参考答案。用“需求、约束、选择、代价、边界”组织回答。
4. 辅助函数通过顶部全文搜索定位；源码附录保存当前后端全部原文件，不需要另外打开项目才能核对上下文。

页面支持章节目录、全文搜索、代码展开、语法高亮、架构图、深浅主题、键盘左右切换，以及本浏览器的阅读位置记录。切换主题只影响教程。阅读进度不是掌握程度的测试结果。

## 文件说明

- `index.html`：交互式阅读入口。
- `project-learning.json`：符合 skill schema 的结构化教程数据。
- `source-snapshot/`：本轮静态读取的源码快照，不含 `.env`。
- `source-manifest.json`：源码文件范围与 SHA256。
- `function-index.json`：函数名称、位置和覆盖方式。
- `validation-report.json`：结构、原代码一致性、逐行覆盖和页面检查记录。
- `vendor/`：页面使用的本地库与来源说明。
- `build/`：本轮构建脚本、模块片段和检查记录，不是业务程序。

## 证据边界

这份教程来自本轮对当前源码、测试文件及保存的评测结果的静态阅读，没有复用旧教程作为事实来源。没有读取实际 `.env`，没有修改业务代码，没有启动业务系统或运行写库/付费模型评测。

事实、设计意图推断、未复现风险与改进建议在正文中分别说明。历史评测结果按日期和分母解释，不代表本轮重新测得的准确率，也不代表生产规模保证。

源码发生变化后，本教程不会自动更新；重新生成前应再次核对代码、依赖、测试和评测证据。
