# 前端界面优化

保留现有绿色风格，优化数据、提问、任务和结果的展示层级，后端接口和统计逻辑保持兼容。

## 已调整

- 数据集信息由原始 JSON 改成四项导入数量与币种、有效状态说明；这些数量是已导入记录总数，不是筛选后的有效订单数。
- 分析偏好与记忆默认折叠；常用问题直接放在提问区，可点击填入并同步更新字数。
- 历史采用侧边原生 dialog，支持 Escape、关闭按钮和遮罩关闭；报告默认折叠，分页请求有重复加载与过期响应保护。
- 任务列表显示状态、模式和北京时间，较长标题限制两行，完整问题仍保存在可访问名称和悬停提示中。
- 执行过程默认显示关键步骤和所有错误，可切换详细过程；工具名称改为中文说明。
- 报告、图表与表格可分别筛选；报告优先展示，支持安全的标题、列表、加粗、表格和代码排版，计算依据可展开，下载内容完整保留。
- 登录、偏好保存及分析提交有忙碌状态；当前会话未结束时阻止重复分析提交。列表内容不变时不重建节点，减少轮询对操作的干扰。
- 增强键盘焦点提示、语义表头与手机布局，修复偏好下拉框中两个不合法 option 标签。

## 实际验证

1. `node --check frontend/app.js`：语法通过。
2. `node --test tests/frontend/report-renderer.test.cjs`：两项离线安全/数据保留测试通过。最小 DOM 测试不代替浏览器验证。
3. 浏览器读取已有报告：三张 Markdown 表格、三段计算依据，6550.00 等金额保留；分类按钮只显示对应结果。
4. 实际偏好保存：两组下拉框各三个选项，柱状图可选，最终恢复测试账号的折线图与简洁说明。
5. 从前端提交规则演示任务，真实 Worker 完成 SQL、绘图、Python 和报告；提交期间按钮禁用，终态恢复可用。
6. 检查历史四条原文、Escape 关闭、手机侧边弹窗范围和详细步骤开关。
7. 设置 390px 测试视口，页面宽度与可用宽度一致，没有横向溢出；数据表在自己的区域横向滚动。随后恢复默认视口。

浏览器验证使用专用 `ui_audit_20261009` 测试账号及模拟数据，不读取其他用户资源，不保存认证令牌。截图保存在 `storage/traces/`。报告渲染支持本项目受控格式；HTML、外链与内联图片不会作为可执行内容解析。
